# Thermal Conductivity Dataset Splits

This document describes the train/test splits generated by `data_spilit.py` for assessing thermal conductivity prediction models.

## Overview

Three distinct train/test splits have been prepared:

1. **Random 80/20 Split**: Standard random baseline split for comparison
2. **Space Group Disjoint Split**: Train and test sets contain completely different space groups
3. **Out-of-Distribution (OOD) Split**: Test set contains low thermal conductivity values

## Data Preprocessing

- **Filtering**: Removed samples where `klat > 10^5`, `klat <= 0`, or non-finite values
- **Target Variable**: `log(klat)` used as Y for both splits
- **Total Valid Samples**: 6,966 (filtered from 6,967 original entries)

## 1. Random 80/20 Split (Baseline)

### Characteristics
- **Train Samples**: 5,563 (79.9%)
- **Test Samples**: 1,403 (20.1%)
- **Sample Overlap**: 0 (no duplicate mp_ids across splits)

### Target Variable Ranges
- **Y_train (log_klat)**: [-12.805, 9.831]
- **Y_test (log_klat)**: [-12.805, 9.831]

### Purpose
This serves as a baseline random split for comparison with the more sophisticated splits. It represents the standard approach where data is randomly divided without considering any domain-specific criteria.

### Selection Criteria
- **Random Assignment**: mp_ids are randomly assigned to train or test sets
- **80/20 Split**: Approximately 80% for training, 20% for testing
- **No Overlap**: Each mp_id appears in only one set (train or test)

## 2. Space Group Disjoint Split

### Characteristics
- **Train Samples**: 5,573 (80.0%)
- **Test Samples**: 1,393 (20.0%)
- **Train Space Groups**: 139 unique space groups
- **Test Space Groups**: 31 unique space groups
- **Space Group Overlap**: 0 (completely disjoint)
- **Sample Overlap**: 0 (no duplicate mp_ids across splits)

### Target Variable Ranges
- **Y_train (log_klat)**: [-11.965, 9.831]
- **Y_test (log_klat)**: [-12.805, 7.507]

### Purpose
This split ensures the model is tested on materials with crystal structures (space groups) not seen during training, evaluating generalization to new structural families.

### Sample Space Groups
- **Train**: Aea2, Ama2, Amm2, C2/c, C2/m, C222_1, Ccc2, Cccm, Cm, Cmc2_1, ...
- **Test**: C2, Cc, Ccce, Fd-3, Fm-3m, Fmm2, I2_13, I4/mmm, Ia-3d, Im-3, ...

## 3. Out-of-Distribution (OOD) Split

### Characteristics
- **Train Samples**: 5,042 (72.4%)
- **Test Samples**: 1,914 (27.5%)
- **Test Threshold**: klat < 1.0
- **Train Threshold**: klat > 0.8
- **Excluded Samples**: 10 (mp_ids with duplicate instances spanning thresholds)
- **Sample Overlap**: 0 (no duplicate mp_ids across splits)

### Target Variable Ranges
- **Y_train (log_klat)**: [-0.223, 9.831] → klat: [0.800, 18592.284]
- **Y_test (log_klat)**: [-12.805, 0.000] → klat: [0.000003, 1.000]

### Purpose
This split tests model performance on materials with low thermal conductivity values, evaluating the model's ability to predict materials with poor thermal conduction.

### Selection Criteria
- **Test Set**: Low thermal conductivity samples (klat < 1.0)
- **Train Set**: Higher thermal conductivity samples (klat > 0.8)
- **Overlap Region**: Samples with 0.8 < klat < 1.0 may appear in either set, but each mp_id appears in only ONE set
- **Duplicate Handling**: 
  - If ALL instances of an mp_id have klat < 1.0 → test set
  - If ALL instances of an mp_id have klat > 0.8 → train set
  - If instances span thresholds → excluded entirely (10 samples)

## Output Files

### Split Data

  - Keys: `split_type`, `train_mp_ids`, `test_mp_ids`, `train_original_indices`, `test_original_indices`, `y_train_log_klat`, `y_test_log_klat`
  
- `processed_splits/space_group_split.pkl`: Space group disjoint split
  - Keys: `split_type`, `train_mp_ids`, `test_mp_ids`, `train_original_indices`, `test_original_indices`, `y_train_log_klat`, `y_test_log_klat`, `train_space_groups`, `test_space_groups`
  
- `processed_splits/ood_split.pkl`: Out-of-distribution split
  - Keys: `split_type`, `train_mp_ids`, `test_mp_ids`, `train_original_indices`, `test_original_indices`, `y_train_log_klat`, `y_test_log_klat`, `train_threshold`, `test_threshold`

## Usage

To regenerate the splits:

```bash
python data_spilit.py
```

To load a split for model training/evaluation:

```python
import pickle

# Load random split (baseline)
with open('processed_splits/random_split.pkl', 'rb') as f:
    random_split = pickle.load(f)

y_train_random = random_split['y_train_log_klat']
y_test_random = random_split['y_test_log_klat']

# Load space group split
with open('processed_splits/space_group_split.pkl', 'rb') as f:
    sg_split = pickle.load(f)

y_train_sg = sg_split['y_train_log_klat']
y_test_sg = sg_split['y_test_log_klat']

# Load OOD split
with open('processed_splits/ood_split.pkl', 'rb') as f:
    ood_split = pickle.load(f)

y_train_ood = ood_split['y_train_log_klat']
y_test_ood = ood_split['y_test_log_klat']
```

## Key Features

1. ✅ Three distinct split strategies: random baseline, space group disjoint, and OOD
2. ✅ Log-transformed target variable (log_klat) for all splits
3. ✅ Filtered klat > 10^5 values
4. ✅ Zero sample overlap across all splits (no duplicate mp_ids)
5. ✅ OOD split with threshold-based separation (test: klat < 1.0, train: klat > 0.8)
6. ✅ Log-scale histogram with 50 bins for OOD split visualization
7. ✅ Rectangle visualization with selective space group labeling (~20 labels)
8. ✅ Strict threshold enforcement for duplicate mp_ids
9. ✅ Reproducible splits with fixed random seeds

## Notes

- The original dataset contained 200 duplicate mp_ids
- **Space Group Split**: Duplicate mp_ids are kept together in the same split based on their space group
- **OOD Split Duplicate Handling**: 
  - If ALL instances of an mp_id meet the test threshold (< 1.0), all assigned to test
  - If ALL instances of an mp_id meet the train threshold (> 0.8), all assigned to train
  - If instances span thresholds, the mp_id is excluded entirely (10 samples excluded)
- This ensures complete sample independence between train and test sets with strict threshold adherence
